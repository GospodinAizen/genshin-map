# Сборка Windows x64

Готовая переносимая сборка создаётся workflow **Windows portable build** на GitHub Actions.

1. Откройте Actions → Windows portable build → Run workflow на ветке `architecture-v2`.
2. Дождитесь успешного завершения всех шагов.
3. Внизу страницы скачайте artifact `GenshinMapOverlay-Windows-x64`.
4. Распакуйте ZIP целиком в отдельную папку.
5. Запустите `Запустить.bat`. Он обновит публичный снимок HoYoLAB и запустит оверлей.

В папке находятся приложение, автономный updater и инструкция. Python на компьютере пользователя не требуется. Первый запуск требует интернет и время на загрузку/построение локального индекса карты. Кэш и прогресс хранятся в профиле пользователя Windows.

## Состав и границы

Сборка содержит настольный оверлей, локальную базу прогресса и официальный публичный снимок карты Тейвата, который updater получает при запуске. Она не содержит проверенных карт всех отдельных регионов/подземелий и не обещает распознавание мини-карты. Полноценную проверку наложения поверх реального клиента Genshin Impact необходимо выполнить на целевой системе; CI проверяет сборку и тесты, но не игровой захват экрана.
